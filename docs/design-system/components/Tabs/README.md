# Tabs

Folder tabs over a 3px baseline that switch the sidebar between Chats and Tasks.

Static rendition, hand-written from `webui/index.css .tabs, .tab (2290–2350)`.

## Spec
Row centred, gap 5px, 3px `color-border` baseline. Tab: padding 8px 16px, 2px `color-border` sides and top, radius 8px 8px 0 0. Active: `color-panel` fill, bold, sits over the baseline. Inactive: `hover-wash` fill, 80% opacity.
