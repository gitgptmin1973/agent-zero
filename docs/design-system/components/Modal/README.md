# Modal

A centred panel over a 50% black backdrop, with a header on color-background and a footer of buttons.

Static rendition, hand-written from `webui/css/modals.css .modal-overlay, .modal-container, .modal-header, .modal-footer (1–235)`.

## Spec
Container `color-panel`, `radius-modal`, `shadow-modal`, up to 1100px wide (95% under 1280px), 90vh max. Header: `color-background`, text `color-primary`, bottom rule `color-border`, close glyph at 70%. Footer: right-aligned, gap 1rem, btn-cancel before btn-ok. Overlay `overlay`, z-index `z-modal`.
