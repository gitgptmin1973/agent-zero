# TextButton

Tiny icon-and-label buttons in the row under the composer: Pause Agent, Import knowledge, Context, History, Nudge.

Static rendition, hand-written from `webui/index.css .text-button (1244–1288)`.

## Spec
Transparent, Rubik 0.6rem, padding `6px spacing-sm`, 80% opacity, 14px icon with `spacing-xs` gap. Hover fills with `color-secondary` at full opacity.

## Don't
Not for primary actions; they read as secondary chrome.
