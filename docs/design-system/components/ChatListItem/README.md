# ChatListItem

One saved chat in the sidebar list, with a bold rail marking the open chat.

Static rendition, hand-written from `webui/index.css .chat-list-button, .chat-name, .chat-list-button.font-bold (225–273, 2419–2445)`.

## Spec
Row padding 8px 5px, radius 4px, hover `hover-wash`. Name 0.8rem, max 160px with ellipsis, its own hover pill `hover-wash-strong`. Current chat: bold plus a 3px `color-border` rail on the left edge. Row actions are EditButtons on the right.
