# EditButton

A 2rem square outline icon button for row-level actions (edit, delete, open) in lists.

Static rendition, hand-written from `webui/index.css .edit-button (1007–1030, light 2026–2038)`.

## Spec
Transparent, 1px `color-border`, `radius-edit` (3px), glyph in `color-primary`. Hover: border `color-primary`, fill `edit-hover`. Pressed: `edit-active`.

## Consumer provides
An icon and an `aria-label`.
