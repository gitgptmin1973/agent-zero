# Toggle

The larger settings toggle: 60×34 track, `info-blue` when on.

Static rendition, hand-written from `webui/css/settings.css .toggle, .toggler (84–122)`.

## Spec
60×34px, radius 34px. Off: `disabled` track. On: `info-blue` track, 26px `on-fill` knob slides 26px. Use inside a settings Field; the sidebar uses Switch instead.
