Settings, navigation and file icons copied verbatim from `webui/public/`. Most are single-ink black (`#000`) strokes or fills on transparent; the app tints them toward `color-primary` with `filter: var(--svg-filter)`, and in dark mode they must be filtered or they disappear. `settings.svg` is drawn in `#e0e0e0`. File-type icons `code`, `image`, `archive`, `backup_restore`, `document`, `file` and `folder` carry their own fills.
